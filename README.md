# Образовательная платформа «Знания»

Это учебный интерактивный веб-проект, изначально разработанный для учеников младших классов в рамках репетиторства, который делает процесс обучения простым, увлекательным и понятным. Сайт предоставляет детям возможность решать задания на разные темы и познавать мир с помощью удобных интерактивных инструментов. 


## 🚀 О проекте

Платформа постоянно развивается и на данный момент содержит некоторое количество образовательных материалов по 8 различным направлениям. Для пользователей реализован личный профиль, где можно отслеживать свои успехи в тестированиях.

## 📚 Направления обучения

На сайте представлены материалы по следующим дисциплинам:
*   **Физика** — 24 материала (включая теоретические разделы и задачи).
*   **Астрономия** — интерактивная симуляция солнечной системы для изучения космоса детьми.
*   **Химия** — 21 материал.
*   **Английский язык** — 19 материалов.
*   **Математика** — 17 материалов (включая модули тестирования).
*   **Квантовая физика** — 12 материалов.
*   **Информатика** и **Биология** — в данный момент находятся в разработке.

## 🛠 Интерактивные инструменты

Для глубокого погружения в предметы мы подготовили ряд уникальных симуляций и интерактивных инструментов:
*   🌌 **Астрономия:** Симуляция Солнечной системы.
*   ⚗️ **Физика:** Изучение атома изнутри — симуляция любого атома.
*   🧪 **Химия:** Интерактивная таблица Менделеева.

## 🧩 Банк задач
В проекте реализован раздел **«Банк задач»**, где все практические задания собраны в одном месте. Вы можете выбрать нужную тему в каталоге задач, решать их и пополнять свою копилку знаний.

## 💻 Технический стек

Проект реализован на классическом стеке веб-технологий, без тяжелых фреймворков:
*   **HTML**
*   **JavaScript**
*   **CSS**

## 📁 Структура репозитория

Основные директории и файлы проекта:
*   `assets/` — медиафайлы и визуальные ресурсы.
*   `js/` — файлы с JavaScript-логикой сайта.
*   `math_moduls/` — задачи, интерактивные инструменты и начальные страницы по математике.
*   `pages/` — основные веб-страницы проекта (теория, контентные блоки).
*   `tasks/` — файлы с учебными заданиями.
*   `other/` — прочие вспомогательные файлы.
*   `index.html` — главная страница образовательной платформы.
*   `profile.html` — страница профиля пользователя.
*   `bank_tasks.html` и `tasks_catalog.html` — страницы банка и каталога задач.
*   `menu.html` — навигационное меню сайта.
