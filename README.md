# Образовательная платформа «Знания»

Это учебный интерактивный веб-проект, разработанный для школьников и подготовки к экзаменам (ОГЭ/ЕГЭ), который делает процесс обучения простым, увлекательным и понятным. Сайт предоставляет ученикам возможность решать задания на разные темы, выполнять домашние задания прямо на платформе и получать персональную обратную связь от преподавателя.


## 🚀 О проекте

Платформа сочетает интерактивные инструменты, симуляции, тренажёры экзаменационных заданий с генерацией прототипов, а также полноценный учебный контур взаимодействия учителя и ученика:
*   📅 **Интерактивный календарь расписания** занятий с привязкой домашних заданий.
*   🛠️ **Конструктор домашних заданий** с мгновенной автогенерацией задач из тренажёров ОГЭ (№6, №8, №9) и устного счёта.
*   📝 **Интерактивное решение Д/З** на платформе с автосохранением черновика, отправкой учителю и пошаговым разбором.
*   🧑‍🏫 **Панель учителя** для проверки работ, сверки ответов, выставления оценок и комментариев.


## 📚 Направления обучения

На сайте представлены материалы по следующим дисциплинам:
*   **Математика и ОГЭ** — тренажёры заданий №6 (дроби/вычисления), №8 (степени/корни), №9 (уравнения), таблицы умножения, модули тестирования.
*   **Физика** — 24 материала (теоретические разделы и задачи).
*   **Астрономия** — интерактивная симуляция Солнечной системы.
*   **Химия** — 21 материал и интерактивная таблица Менделеева.
*   **Английский язык** — 19 материалов.
*   **Квантовая физика** — 12 материалов.
*   **Информатика** и **Биология** — в разработке.


## 🛠 Интерактивные инструменты

*   🌌 **Астрономия:** Симуляция Солнечной системы.
*   ⚗️ **Физика:** Изучение атома изнутри — симуляция строения атомов.
*   🧪 **Химия:** Интерактивная таблица Менделеева.
*   🎯 **Тренажёры ОГЭ:** Динамическая генерация бесконечного числа вариантов с подсказками и пошаговым решением.


## 💻 Технический стек

Проект реализован на классическом стеке веб-технологий без тяжелых фреймворков и внешних СУБД:
*   **Python 3 + Flask** — серверная часть, маршрутизация и REST API.
*   **SQLite 3** — встроенная реляционная база данных (минимальное потребление памяти, без внешних зависимостей, оптимизировано под бесплатный хостинг PythonAnywhere с лимитом 512 МБ).
*   **HTML5 & CSS3** — адаптивный дизайн с поддержкой тёмной и светлой тем.
*   **Vanilla JavaScript (ES6+)** — клиентская интерактивность, математический рендеринг и автосинхронизация с сервером (`js/auth_sync.js`).


## 🗄️ База данных и модель данных (`db.py`)

*   `users` — идентификаторы, уникальные логины, отображаемые имена, надёжные хэши паролей (PBKDF2-SHA256), роли (`student`, `teacher`, `admin`) и даты активности.
*   `user_data` — прогресс пользователя (опыт XP, решённые задачи, рамка аватара, тема оформления, серии и звания в тренажёрах, медали).
*   `classes` — учебные классы преподавателей.
*   `class_members` — зачисление учеников в классы с индексами быстрого поиска.
*   `lessons` — расписание занятий с датой/временем, темой, заметками и прикреплённым домашним заданием.
*   `homeworks` — домашние задания с JSON-массивом условий, правильных ответов и шагов разбора.
*   `homework_submissions` — сданные учениками работы: ответы, статус (`pending`, `submitted`, `checked`), балл и комментарий учителя.


## 🎓 Личный кабинет ученика (`profile.html`)

Интерфейс профиля переработан для максимального удобства и отсутствия перегруженности:
1. **«📅 Учёба и расписание» (Центральная вкладка по умолчанию):**
   *   Карточка «Ближайшее занятие» с обратным отсчётом/датой, темой урока и кнопкой быстрого перехода к прикреплённому Д/З.
   *   Интерактивный календарь текущего месяца с цветовой индикацией уроков и дедлайнов Д/З.
   *   Панель событий выбранного дня.
   *   Список домашних заданий с актуальными статусами (Не начато / В процессе / На проверке / Проверено).
2. **«📊 Прогресс и навыки»:** общая статистика решений, точность, опыт XP и график успеваемости.
3. **«🔥 Серии и звания»:** карточки тренажёров с текущими званиями и прогресс-барами.
4. **«🏆 Медали»:** достижения и награды за успехи в обучении.
5. **«⚙️ Настройки»:** кастомизация профиля (рамки аватаров, тема оформления, экспорт/импорт).


## 📝 Интерактивное решение домашнего задания (`homework.html`)

*   Карточки с качественным оформлением условий, дробей, квадратных корней и степеней.
*   Удобное поле ввода ответа с поддержкой запятых/точек.
*   Автоматическое фоновое сохранение черновика при наборе ответов.
*   Модальное окно подтверждения сдачи работы учителю.
*   После проверки учителем: отображение статуса верности каждого номера, правильных ответов, набранных баллов, комментария преподавателя и раскрывающегося пошагового разбора решения.


## 🧑‍🏫 Панель учителя (`teacher.html`)

Доступна по ссылке «Для учителей» в футере сайта или по адресу `/teacher`:
*   **«🏫 Мои классы»:** создание учебных групп, просмотр состава класса и быстрое зачисление учеников.
*   **«📅 Расписание»:** планирование уроков, выбор класса, времени, прикрепление Д/З и ссылок на онлайн-уроки.
*   **«🛠️ Конструктор Д/З»:**
    *   Автогенерация задач из тренажёров ОГЭ №6, №8, №9, таблицы умножения.
    *   Добавление авторских задач вручную.
    *   Управление составом задания в корзине перед публикацией.
*   **«📝 Проверка работ»:**
    *   Просмотр списка сданных работ учеников.
    *   Автоматическая сверка ответов учеников с эталонными.
    *   Выставление итоговой оценки и текстового комментария/подсказок для ученика.
*   **«👥 Все пользователи»:** мониторинг всех зарегистрированных пользователей платформы, их XP, успеваемости и открытие личного досье.
*   **«⚡ Живая лента»:** хроника решений заданий учениками в реальном времени.


## 🚀 Запуск проекта через Flask

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Запустите сервер:
```bash
python main.py
```
По умолчанию сайт откроется по адресу [http://127.0.0.1:5000](http://127.0.0.1:5000).

Параметры запуска:
```bash
python main.py --port 8080
python main.py --host 0.0.0.0 --port 5000 --debug
```

Управление ролями через консоль:
```bash
python main.py --list-users
python main.py --make-teacher <username>
python main.py --set-role <username> <role>
```

Подробные инструкции по работе на хостинге PythonAnywhere и оптимизации SQLite доступны в файле `instruction.txt`.


## 📁 Структура репозитория

*   `main.py` — серверное приложение на Flask и REST API.
*   `db.py` — модуль работы с базой данных SQLite.
*   `index.html` — главная страница платформы.
*   `profile.html` — личный кабинет ученика (расписание, календарь, прогресс, звания, медали).
*   `teacher.html` — панель учителя (классы, расписание, конструктор Д/З, проверка работ, мониторинг).
*   `homework.html` — плеер интерактивного решения и сдачи домашнего задания.
*   `wsgi.py` — WSGI-конфигурация для хостинга PythonAnywhere.
*   `instruction.txt` — справочник консольных команд и шпаргалка по хостингу (добавлен в `.gitignore`).
*   `js/` — клиентские скрипты, тренажёры ОГЭ №6, №8, №9, автосинхронизация (`auth_sync.js`).
*   `assets/` — стили, шрифты WOFF2 и фоновые изображения.
