# Образовательная платформа «Знания»

Это учебный интерактивный веб-проект, изначально разработанный для учеников младших классов в рамках репетиторства, который делает процесс обучения простым, увлекательным и понятным. Сайт предоставляет детям возможность решать задания на разные темы и познавать мир с помощью удобных интерактивных инструментов. 


## 🚀 О проекте

Платформа постоянно развивается и на данный момент содержит некоторое количество образовательных материалов по 8 различным направлениям. Для пользователей реализован личный профиль, где можно отслеживать свои успехи в тестированиях.

## 📚 Направления обучения

На сайте представлены материалы по следующим дисциплинам:
*   **Физика** — 24 материала (включая теоретические разделы и задачи).
*   **Астрономия** — интерактивная симуляция солнечной системы для изучения космоса детьми.
*   **Химия** — 21 материал.
*   **Английский язык** — 19 материалов.
*   **Математика** — 17 материалов (включая модули тестирования).
*   **Квантовая физика** — 12 материалов.
*   **Информатика** и **Биология** — в данный момент находятся в разработке.

## 🛠 Интерактивные инструменты

Для глубокого погружения в предметы мы подготовили ряд уникальных симуляций и интерактивных инструментов:
*   🌌 **Астрономия:** Симуляция Солнечной системы.
*   ⚗️ **Физика:** Изучение атома изнутри — симуляция любого атома.
*   🧪 **Химия:** Интерактивная таблица Менделеева.

## 🧩 Банк задач
В проекте реализован раздел **«Банк задач»**, где все практические задания собраны в одном месте. Вы можете выбрать нужную тему в каталоге задач, решать их и пополнять свою копилку знаний.

## 💻 Технический стек

Проект реализован на классическом стеке веб-технологий, без тяжелых фреймворков и сторонних СУБД:
*   **Python 3 + Flask** — серверная часть для локального запуска, маршрутизации и API.
*   **SQLite 3** — встроенная реляционная база данных (минимальное потребление памяти, без внешних зависимостей, оптимизировано под бесплатный хостинг PythonAnywhere с лимитом 512 МБ).
*   **HTML5**
*   **JavaScript (ES6+)** — клиентская логика, автосинхронизация прогресса с облаком (`js/auth_sync.js`).
*   **CSS3** — адаптивный дизайн с поддержкой тёмной и светлой тем.

## 🗄️ База данных и авторизация пользователей

*   **Модель данных (`db.py`):**
    *   `users` — идентификаторы, уникальные логины (регистронезависимые), отображаемые имена, надёжные хэши паролей (PBKDF2-SHA256) и даты входа.
    *   `user_data` — прогресс пользователя (опыт XP, решённые задачи, рамка аватара, тема оформления, серии и звания в тренажёрах, медали).
*   **Авторизация и сессии (`main.py`):**
    *   Криптографически подписанные HTTP-only cookies Flask сессии (не расходуют дисковое пространство сервера).
    *   `POST /api/auth/register` — регистрация с сохранением накопленного гостевого прогресса.
    *   `POST /api/auth/login` — авторизация и загрузка прогресса из БД.
    *   `POST /api/auth/logout` — завершение сессии.
    *   `GET /api/user/data` и `POST /api/user/sync` — автоматическая синхронизация прогресса при решении задач.

## 🚀 Запуск проекта через Flask

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Запустите сервер:
```bash
python main.py
```

По умолчанию сайт откроется по адресу [http://127.0.0.1:5000](http://127.0.0.1:5000).

Дополнительные параметры запуска:
```bash
# Запуск на другом порту
python main.py --port 8080

# Доступ из локальной сети и режим отладки
python main.py --host 0.0.0.0 --port 5000 --debug
```

## 🌐 Развёртывание на PythonAnywhere (Бесплатный тариф)

Проект полностью оптимизирован под бесплатный аккаунт [PythonAnywhere](https://www.pythonanywhere.com/) (ограничение 512 МБ дискового пространства и отсутствие постоянных демонов):

1. **Загрузите репозиторий на PythonAnywhere:**
   В консоли Bash:
   ```bash
   git clone https://github.com/VolentCry/<repo_name>.git study_site
   cd study_site
   pip install --user -r requirements.txt
   ```
2. **Настройте вкладку Web:**
   * Создайте **Manual Configuration** (Python 3.10 / 3.11 / 3.12).
   * В поле **Source code** укажите: `/home/<username>/study_site`.
   * Откройте **WSGI configuration file** и замените его содержимое на:
     ```python
     import sys
     path = '/home/<username>/study_site'
     if path not in sys.path:
         sys.path.append(path)

     from wsgi import application
     ```
3. **Нажмите кнопку «Reload»** — сайт запущен и сразу готов к работе с базой данных SQLite!
