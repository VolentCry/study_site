Алгебра · Функции 01

Функция. Линейная функция

Уравнение прямой y = kx + b

Функция — зависимость переменной y от переменной x, при которой каждому значению независимой переменной x (аргумента) соответствует единственное значение зависимой переменной y.

  • График: графиком линейной функции является прямая линия. Для её построения достаточно найти координаты двух любых точек.
  • Коэффициент k (угловой): определяет наклон прямой. При k > 0 функция возрастает, при k < 0 — убывает, при k = 0 — график параллелен оси Ox (y = b).
  • Свободный член b: ордината точки пересечения с осью Oy — точка (0; b). Если b = 0, то y = kx — прямая пропорциональность (проходит через начало координат (0; 0)).
  • Взаимное расположение: если k₁ = k₂ и b₁ ≠ b₂ — прямые параллельны; если k₁ ≠ k₂ — пересекаются; если k₁ = k₂ и b₁ = b₂ — совпадают.

Алгебра · Выражения 02

Одночлены

Стандартный вид a · xmyn...

Одночлен — выражение, представляющее собой произведение чисел, переменных и их натуральных степеней (числа, переменные и их степени — тоже одночлены).

  • Стандартный вид: числовой множитель (коэффициент) стоит на первом месте, а каждая переменная записана один раз в виде степени (например: 3x · 2x²y = 6x³y).
  • Коэффициент: числовой множитель одночлена в стандартном виде. У одночлена x коэффициент равен 1, у -x равен -1.
  • Степень одночлена: сумма показателей степеней всех входящих в него переменных. У 5x³y² степень равна 3 + 2 = 5. Степень ненулевого числа равна 0.
  • Подобные одночлены: одночлены с одинаковой буквенной частью. При приведении складываются коэффициенты: 7a²b - 3a²b = 4a²b.
  • Действия: при умножении коэффициенты перемножаются, а показатели одинаковых переменных складываются: (2x²y) · (-3xy³) = -6x³y⁴. При возведении в степень возводится каждый множитель: (-2x³)² = 4x⁶.

Алгебра · Степени 03

Свойство степеней

Определение степени an = a · a · ... · a

Степенью числа a с натуральным показателем n > 1 называют произведение n множителей, каждый из которых равен a (при n = 1: a¹ = a).

  • Умножение степеней: am · an = am + n (основание остаётся прежним, показатели складываются).
  • Деление степеней: am : an = am - n (при a ≠ 0, m > n; показатели вычитаются).
  • Возведение степени в степень: (am)n = am · n (показатели перемножаются).
  • Степень произведения: (ab)n = an · bn (каждый множитель возводится в эту степень).
  • Степень дроби: (a / b)n = an / bn (при b ≠ 0).
  • Нулевая степень и знаки: a⁰ = 1 (при a ≠ 0). Отрицательное число в чётной степени положительно: (-a)²ⁿ = a²ⁿ, а в нечётной — отрицательно: (-a)²ⁿ⁺¹ = -a²ⁿ⁺¹.
