Задание №7 Прототип ОГЭ
Синтаксис URL

Всегда строго по шаблону: протокол://сервер/каталог/имя_файла.расширение.

Ограничения IPv4

4 числа от 0 до 255, разделённые 3 точками. Фрагмент, начинающийся с точки, не может быть первым; при склейке чисел между точками нельзя получить число больше 255.
