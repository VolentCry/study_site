💡 Пошаговое решение по критериям ФИПИ

📖 Справочник по заданию №20 ОГЭ (Часть 2)

1. Биквадратные уравнения: ax⁴ + bx² + c = 0

Вводим замену переменной: пусть t = x², при этом обязательно указывать условие t ≥ 0. Решаем квадратное уравнение at² + bt + c = 0. Если один из корней t < 0, обязательно пишем: «не удовлетворяет условию t ≥ 0, корней нет». Для t > 0 делаем обратную замену: x = ±√t.

2. Уравнения вида x⁴ = (ax + b)²

Ни в коем случае не раскрывайте бином 4-й степени! Перенесите выражение в левую часть и примените формулу разности квадратов:
(x²)² − (ax + b)² = 0 ⟹ (x² − (ax + b))(x² + (ax + b)) = 0.
Каждую скобку приравниваем к нулю и решаем два квадратных уравнения.

3. Уравнения 3-й степени (метод группировки)

Группируем слагаемые парами: (x³ + ax²) − (bx + ab) = 0. Выносим общий множитель из каждой пары: x²(x + a) − b(x + a) = 0. Затем выносим общую скобку: (x + a)(x² − b) = 0.

4. Учёт ОДЗ при взаимном уничтожении корней

Если в уравнении есть слагаемые с квадратным корнем +√(k − x) слева и справа, их нельзя просто зачеркнуть без нахождения ОДЗ! Сначала записываем: ОДЗ: k − x ≥ 0 ⟹ x ≤ k. После нахождения корней квадратного уравнения отбрасываем те, которые не удовлетворяют ОДЗ.

5. Дробно-рациональные неравенства методом интервалов

• Неравенство −C / ((x − a)² − b²) ≥ 0: так как числитель −C < 0, то дробь ≥ 0 тогда и только тогда, когда знаменатель строго меньше нуля: (x − a)² − b² < 0 (скобки строго круглые!).
• В дробных неравенствах нули знаменателя всегда выколоты (круглая скобка), а нули числителя закрашены (квадратная скобка) только если знак неравенства нестрогий (≤ или ≥).
• Запрещено умножать неравенство на выражение с переменной, знак которого может меняться!

6. Системы уравнений второй части

• Метод сложения: складываем уравнения, чтобы исключить одну из переменных (например, +y и −y или с одинаковыми коэффициентами при x²).
• Метод подстановки: выражаем переменную первой степени через другую и подставляем в квадратное уравнение.
• Запись ответа: решения записываются strictly упорядоченными парами (x; y) через точку с запятой.
