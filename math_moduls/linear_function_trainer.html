1. Общий вид линейной функции

y = kx + b

k — угловой коэффициент (наклон прямой), b — ордината точки пересечения с осью Oy.

x — аргумент (независимая переменная), y — значение функции (зависимая переменная).

2. Область определения D(y)

Для обычной линейной функции y = kx + b аргумент x может быть любым числом: (−∞; +∞).

Если задано условие a ≤ x ≤ c, область определения — промежуток [a; c].

3. Пересечение с осями координат

• С осью Ox (абсцисс): полагаем y = 0, решаем kx + b = 0 ⟹ x = −b/k. Точка: (x; 0).

• С осью Oy (ординат): полагаем x = 0, получаем y = b. Точка: (0; b).

4. Пересечение двух графиков

В точке пересечения (x₀; y₀) значения обеих функций совпадают: k₁x + b₁ = k₂x + b₂.

Находим x, затем подставляем в любую формулу и находим y.
