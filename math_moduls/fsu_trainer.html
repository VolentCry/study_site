Квадрат суммы:
(a + b)² = a² + 2ab + b²

Квадрат первого + удвоенное произведение + квадрат второго

Квадрат разности:
(a - b)² = a² - 2ab + b²

Квадрат первого минус удвоенное произведение + квадрат второго

Разность квадратов:
a² - b² = (a - b)(a + b)

Произведение разности двух выражений на их сумму

Быстрый счёт (пример):
79 · 81 = 80² - 1² = 6399

Используем (a - 1)(a + 1) = a² - 1 для мгновенного счёта
