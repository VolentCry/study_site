📖 Формулы и алгоритмы для Задания №7

1. Оценка квадратных корней на координатной прямой:
Чтобы найти положение корня вида √n между целыми числами, определите два ближайших точных квадрата:
k² < n < (k + 1)², следовательно k < √n < k + 1.
Пример: 36 < 39 < 49, значит 6 < √39 < 7. Чтобы узнать, к какому краю ближе корень, возведите в квадрат середину: 6,5² = 42,25. Так как 39 < 42,25, число √39 лежит левее середины (ближе к 6).
2. Расположение обыкновенных дробей:
Чтобы нанести дробь вида a/b на числовую прямую, переведите её в десятичную делением числителя на знаменатель столбиком до 1–2 знаков после запятой.
Пример: 43/7 = 6 1/7 = 6 + 0,14... ≈ 6,14. Значит, точка лежит чуть правее 6.
3. Неравенства с переменными (метод пробных чисел):
Если на прямой отмечены переменные x, y относительно 0, выпишите их приблизительные числовые значения с учётом знаков (например, x = −1,8; y = 2,7). Подставьте эти числа в каждое утверждение для быстрой и надёжной проверки.
4. Сравнение разностей:
• Если точка a лежит правее точки b (a > b), то разность a − b > 0 (положительна).
• Если точка a лежит левее точки b (a < b), то разность a − b < 0 (отрицательна).
5. Запись ответа в бланк ОГЭ:
В бланке ответов ОГЭ №1 для Задания 7 записывается ТОЛЬКО одна цифра — номер выбранного варианта ответа (1, 2, 3 или 4) без пробелов, запятых и пояснений.
