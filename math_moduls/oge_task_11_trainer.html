💡 Пошаговое решение задания:

📖 Справочные формулы и свойства графиков (№11 ОГЭ)

1. Линейная функция: y = kx + b (прямая)

• Коэффициент k (угловой коэффициент): отвечает за угол наклона прямой к оси Ox. Если k > 0 — угол острый, функция возрастает (слева направо идёт вверх). Если k < 0 — угол тупой, функция убывает.

• Коэффициент b: ордината точки пересечения с осью Oy (точка (0; b)). Если b > 0 — пересекает Oy выше оси Ox; если b < 0 — ниже.

2. Квадратичная функция: y = ax² + bx + c (парабола)

• Коэффициент a: направление ветвей. Если a > 0 — ветви направлены вверх. Если a < 0 — ветви направлены вниз.

• Коэффициент c: ордината точки пересечения с осью Oy: y(0) = c (точка (0; c)).

• Вершина параболы: абсцисса вершины вычисляется по формуле: x₀ = -b / (2a). Подставив x₀ в формулу, находим y₀.

• Дискриминант D = b² - 4ac: если D > 0 — парабола пересекает Ox в двух точках; если D = 0 — вершина касается Ox; если D < 0 — пересечений с Ox нет.

3. Обратная пропорциональность: y = k / x (гипербола)

• График состоит из двух ветвей и никогда не пересекает оси координат (так как x ≠ 0 и y ≠ 0).

• Если k > 0 — ветви лежат в I и III координатных четвертях.

• Если k < 0 — ветви лежат во II и IV координатных четвертях.

• Значение k легко проверить по контрольной точке: k = x · y.

4. Функция квадратного корня: y = √x

• График представляет собой верхнюю ветвь параболы, выходящую из начала координат (0; 0) вправо-вверх (область определения x ≥ 0, y ≥ 0).
