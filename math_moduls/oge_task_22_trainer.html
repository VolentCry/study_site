⚖️ Критерии оценивания задания №22 (2 балла):
• 2 балла: График построен абсолютно верно (указаны масштаб, оси, выколотые точки или разрывы, вершины параболы), верно найдены и обоснованы все значения параметра.

• 0 баллов: График построен неверно (пропущены выколотые точки, неверно определено направление ветвей), либо решение не соответствует критериям на 1–2 балла.

📖 Справочник по заданию №22 ОГЭ (Часть 2)

1. Алгоритм построения кусочной функции

1. В тетради нарисуйте декартову систему координат, подписав оси x, y, начало координат O и единичные отрезки (обычно 1 или 2 клетки).
2. Разбейте числовую прямую вертикальными пунктирными линиями на промежутки задания функции.
3. Для каждого промежутка составьте небольшую таблицу значений (минимум 2 точки для прямой, 3–5 точек для параболы с обязательной вершиной xв = −b / (2a)).
4. Особое внимание уделите граничным точкам: закрашенная точка при знаках ≤, ≥ и выколотая при строгих <, > (если соседняя ветвь не заполняет этот стык).

2. Дробно-рациональные функции и выколотые точки

Если функция задана дробью, например y = (x² + 5x + 6) / (x + 2):
• Сначала обязательно выписываем ОДЗ: знаменатель не равен нулю (x + 2 ≠ 0 ⟹ x ≠ −2).
• Раскладываем числитель на множители: (x + 2)(x + 3) / (x + 2) = x + 3.
• Строим график итоговой простой функции (прямая y = x + 3).
• Обязательно выкалываем на графике точку с абсциссой x = −2 (ордината y = −2 + 3 = 1, точка (−2; 1) рисуется пустой внутри!).

3. Исследование прямых y = m (горизонтальные прямые)

Прямая y = m параллельна оси абсцисс Ox.
Представьте, что горизонтальная прямая плавно поднимается снизу вверх от m = −∞ до m = +∞.
Критическими уровнями, где меняется число пересечений, всегда являются:
• Вершины парабол (касание);
• Горизонтальные асимптоты гипербол (y = 0 или y = c);
• Выколотые точки графика (пересечение пропадает!);
• Стыки и точки изломов кусочной функции.

4. Исследование прямых y = kx (пучок прямых из начала координат)

Прямая y = kx проходит через начало координат (0; 0).
При изменении углового коэффициента k прямая вращается вокруг точки (0; 0).
Ровно одну общую точку с гиперболой прямая y = kx имеет тогда, когда она проходит через выколотую точку (подставляем координаты выколотой точки в y = kx и находим k).
