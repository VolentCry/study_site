## Задача 1
###### Тип: Насыщенный пар (свойства и изотермические процессы)
**Условие:**
![[Задача на влажность. Задача 1.png]]
В плотно закрытом сосуде при постоянной температуре находятся вода и её насыщенный водяной пар. Как изменятся плотность и давление пара, если объём сосуда изотермически уменьшить в $2$ раза?

| Дано: | Найти: |
| :--- | :--- |
| $T = \text{const}$ | $\rho_2 / \rho_1$ — ? |
| $V_2 = V_1 / 2$ | $p_2 / p_1$ — ? |
| Вода + насыщенный пар | |

**Решение:**  
1. Плотность $\rho_0$ и давление $p_0$ насыщенного пара зависят **только от температуры** и не зависят от объёма, занимаемого паром.  
2. При сжатии в начальный момент концентрация молекул возрастает, скорость конденсации превышает скорость испарения, и избыток пара переходит в жидкость до тех пор, пока вновь не установится динамическое равновесие.  
3. Так как температура не изменилась ($T = \text{const}$), плотность и давление пара останутся прежними:  
   $$\rho_2 = \rho_1 = \rho_0(T), \quad p_2 = p_1 = p_0(T)$$

**Ответ:** плотность и давление насыщенного пара не изменятся.

## Задача 2
###### Тип: Относительная влажность и плотность пара
**Условие:**
![[Задача на влажность. Задача 2.png]]
В комнате объёмом $50\text{ м}^3$ при температуре $20\text{ }^\circ\text{C}$ содержится $600\text{ г}$ водяного пара. Плотность насыщенного водяного пара при этой температуре равна $17{,}3\text{ г/м}^3$. Найдите относительную влажность воздуха в комнате.

| Дано: | СИ: | Найти: |
| :--- | :--- | :--- |
| $V = 50\text{ м}^3$ | | $\varphi$ — ? |
| $t = 20\text{ }^\circ\text{C}$ | | |
| $m = 600\text{ г}$ | | |
| $\rho_0 = 17{,}3\text{ г/м}^3$ | | |

**Решение:**  
1. Определим абсолютную влажность воздуха (плотность водяного пара в комнате):  
   $$\rho = \frac{m}{V} = \frac{600}{50} = 12\text{ г/м}^3$$  
2. Вычислим относительную влажность воздуха:  
   $$\varphi = \frac{\rho}{\rho_0} \cdot 100\%$$  
   $$\varphi = \frac{12}{17{,}3} \cdot 100\% \approx 69{,}36\% \approx 69\%$$

**Ответ:** $\varphi \approx 69\%$.

## Задача 3
###### Тип: Психрометр и влажность
**Условие:**
![[Задача на влажность. Задача 3.png]]
Сухой термометр психрометра показывает $22\text{ }^\circ\text{C}$, а влажный — также $22\text{ }^\circ\text{C}$. Чему равна относительная влажность воздуха в помещении? Объясните физическую причину равенства показаний.

| Дано: | Найти: |
| :--- | :--- |
| $t_{\text{сух}} = 22\text{ }^\circ\text{C}$ | $\varphi$ — ? |
| $t_{\text{вл}} = 22\text{ }^\circ\text{C}$ | Причина равенства |

**Решение:**  
1. Разность показаний термометров:  
   $$\Delta t = t_{\text{сух}} - t_{\text{вл}} = 22 - 22 = 0\text{ }^\circ\text{C}$$  
2. Влажный термометр охлаждается только за счёт испарения воды с поверхности фитиля. Если $t_{\text{сух}} = t_{\text{вл}}$, испарение отсутствует или скорость конденсации равна скорости испарения.  
3. Это возможно исключительно в ситуации, когда водяной пар в воздухе уже является насыщенным ($\varphi = 100\%$).

**Ответ:** $\varphi = 100\%$; испарение с ткани прекратилось, так как пар в воздухе насыщен.

## Задача 4
###### Тип: Относительная влажность и плотность пара
**Условие:**
![[Задача на влажность. Задача 4.png]]
Парциальное давление водяного пара в воздухе при температуре $25\text{ }^\circ\text{C}$ равно $1{,}58\text{ кПа}$, а давление насыщенного пара при той же температуре составляет $3{,}16\text{ кПа}$. Определите относительную влажность воздуха.

| Дано: | СИ: | Найти: |
| :--- | :--- | :--- |
| $t = 25\text{ }^\circ\text{C}$ | | $\varphi$ — ? |
| $p = 1{,}58\text{ кПа}$ | $1580\text{ Па}$ | |
| $p_0 = 3{,}16\text{ кПа}$ | $3160\text{ Па}$ | |

**Решение:**  
1. Относительная влажность через парциальное давление выражается формулой:  
   $$\varphi = \frac{p}{p_0} \cdot 100\%$$  
2. Подставим значения:  
   $$\varphi = \frac{1{,}58}{3{,}16} \cdot 100\% = 0{,}5 \cdot 100\% = 50\%$$

**Ответ:** $\varphi = 50\%$.

## Задача 5
###### Тип: Изменение влажности и массы пара в замкнутом объеме
**Условие:**
![[Задача на влажность. Задача 5.png]]
Герметично закрытый стеклянный сосуд заполнен только ненасыщенным водяным паром (жидкости внутри нет). Как изменятся абсолютная влажность и относительная влажность воздуха в сосуде при его нагревании?

| Дано: | Найти: |
| :--- | :--- |
| $V = \text{const}$ | Изменение $\rho$ |
| $m = \text{const}$ | Изменение $\varphi$ |
| Нагревание: $T_2 > T_1$ | |

**Решение:**  
1. Абсолютная влажность — это плотность пара:  
   $$\rho = \frac{m}{V}$$  
   Поскольку сосуд запаян ($m = \text{const}$) и его объём постоянен ($V = \text{const}$), абсолютная влажность **не изменится**.
2. Относительная влажность:  
   $$\varphi = \frac{\rho}{\rho_0(T)} \cdot 100\%$$  
3. С ростом температуры плотность насыщенного пара $\rho_0(T)$ быстро возрастает, поэтому отношение $\rho / \rho_0(T)$ уменьшается.

**Ответ:** абсолютная влажность не изменится, относительная влажность уменьшится.

## Задача 6
###### Тип: Точка росы и конденсация
**Условие:**
![[Задача на влажность. Задача 6.png]]
Днём при температуре $20\text{ }^\circ\text{C}$ относительная влажность воздуха составляла $60\%$. Выпадет ли роса ночью, если температура воздуха опустится до $10\text{ }^\circ\text{C}$?  
(Плотность насыщенного пара при $20\text{ }^\circ\text{C}$ равна $17{,}3\text{ г/м}^3$, а при $10\text{ }^\circ\text{C}$ — $9{,}4\text{ г/м}^3$).

| Дано: | Найти: |
| :--- | :--- |
| $t_1 = 20\text{ }^\circ\text{C}$ | Выпадет ли роса? |
| $\varphi_1 = 60\%$ ($0{,}60$) | |
| $\rho_{01} = 17{,}3\text{ г/м}^3$ | |
| $t_2 = 10\text{ }^\circ\text{C}$ | |
| $\rho_{02} = 9{,}4\text{ г/м}^3$ | |

**Решение:**  
1. Найдём фактическую плотность водяного пара в воздухе (абсолютную влажность):  
   $$\rho = \varphi_1 \cdot \rho_{01} = 0{,}60 \cdot 17{,}3 = 10{,}38\text{ г/м}^3$$  
2. При ночном охлаждении до $10\text{ }^\circ\text{C}$ воздух максимально может удерживать в виде пара лишь $\rho_{02} = 9{,}4\text{ г/м}^3$.  
3. Сравним значения:  
   $$\rho = 10{,}38\text{ г/м}^3 > 9{,}4\text{ г/м}^3$$  
   Воздух пересыщается влагой, и избыток пара ($\Delta \rho = 10{,}38 - 9{,}4 = 0{,}98\text{ г/м}^3$) сконденсируется в капли росы.

**Ответ:** да, роса выпадет.

## Задача 7
###### Тип: Психрометр и влажность
**Условие:**
![[Задача на влажность. Задача 7.png]]
В двух одинаковых комнатах поддерживается постоянная температура воздуха $20\text{ }^\circ\text{C}$. В первой комнате разность показаний сухого и влажного термометров психрометра равна $4\text{ }^\circ\text{C}$, а во второй комнате — $7\text{ }^\circ\text{C}$. В какой из комнат относительная влажность воздуха выше? Ответ обоснуйте.

| Дано: | Найти: |
| :--- | :--- |
| $t_1 = t_2 = 20\text{ }^\circ\text{C}$ | В какой комнате $\varphi$ выше? |
| $\Delta t_1 = 4\text{ }^\circ\text{C}$ | |
| $\Delta t_2 = 7\text{ }^\circ\text{C}$ | |

**Решение:**  
1. Охлаждение влажного термометра происходит из-за испарения воды с его фитиля. Чем суше воздух, тем быстрее испаряется вода и тем сильнее падает температура влажного термометра.  
2. Соответственно, большая разность $\Delta t$ соответствует более сухому воздуху.  
3. Так как $\Delta t_1 < \Delta t_2$ ($4\text{ }^\circ\text{C} < 7\text{ }^\circ\text{C}$), испарение в первой комнате идёт слабее, что указывает на более высокое содержание влаги относительно насыщения.

**Ответ:** в первой комнате относительная влажность выше.

## Задача 8
###### Тип: Изменение влажности и массы пара в замкнутом объеме
**Условие:**
![[Задача на влажность. Задача 8.png]]
Относительная влажность воздуха в закрытом баллоне объёмом $2\text{ м}^3$ при температуре $15\text{ }^\circ\text{C}$ составляет $40\%$. Какую массу воды необходимо дополнительно испарить в этот баллон при неизменной температуре, чтобы повысить относительную влажность до $90\%$?  
(Плотность насыщенного пара при $15\text{ }^\circ\text{C}$ равна $12{,}8\text{ г/м}^3$).

| Дано: | СИ: | Найти: |
| :--- | :--- | :--- |
| $V = 2\text{ м}^3$ | | $\Delta m$ — ? |
| $t = 15\text{ }^\circ\text{C}$ | | |
| $\varphi_1 = 40\%$ | $0{,}4$ | |
| $\varphi_2 = 90\%$ | $0{,}9$ | |
| $\rho_0 = 12{,}8\text{ г/м}^3$ | | |

**Решение:**  
1. Начальная плотность пара в баллоне:  
   $$\rho_1 = \varphi_1 \cdot \rho_0 = 0{,}4 \cdot 12{,}8 = 5{,}12\text{ г/м}^3$$  
2. Требуемая конечная плотность пара:  
   $$\rho_2 = \varphi_2 \cdot \rho_0 = 0{,}9 \cdot 12{,}8 = 11{,}52\text{ г/м}^3$$  
3. Необходимое изменение плотности пара:  
   $$\Delta \rho = \rho_2 - \rho_1 = 11{,}52 - 5{,}12 = 6{,}4\text{ г/м}^3$$  
4. Масса воды, которую нужно дополнительно испарить:  
   $$\Delta m = \Delta \rho \cdot V = 6{,}4 \cdot 2 = 12{,}8\text{ г}$$

**Ответ:** $\Delta m = 12{,}8\text{ г}$.

## Задача 9
###### Тип: Качественные и прикладные вопросы влажности
**Условие:**
![[Задача на влажность. Задача 9.png]]
Что с точки зрения молекулярно-кинетической теории означает утверждение: «Пар над поверхностью жидкости стал насыщенным»? В чём состоит сущность состояния динамического равновесия?

| Дано: | Найти: |
| :--- | :--- |
| Пар в равновесии с жидкостью | Физический смысл динамического равновесия |

**Решение:**  
1. С поверхности любой жидкости непрерывно вылетают наиболее быстрые молекулы (процесс испарения). Одновременно молекулы пара из воздуха хаотически соударяются с поверхностью жидкости и возвращаются обратно (процесс конденсации).  
2. Если сосуд герметично закрыт, число молекул пара в пространстве над жидкостью увеличивается, и частота их возвращения возрастает.  
3. Состояние, при котором **число молекул, покидающих жидкость в единицу времени, становится равным числу молекул, возвращающихся в неё за то же время**, называется **динамическим равновесием**. Пар, находящийся в таком состоянии со своей жидкостью, называют **насыщенным**.

**Ответ:** равенство скоростей испарения и конденсации молекул на границе раздела фаз.

## Задача 10
###### Тип: Точка росы и конденсация
**Условие:**
При температуре воздуха $18\text{ }^\circ\text{C}$ точка росы оказалась равной $10\text{ }^\circ\text{C}$. Чему равна абсолютная влажность воздуха в помещении?  
(Плотность насыщенного пара при $18\text{ }^\circ\text{C}$ равна $15{,}4\text{ г/м}^3$, а при $10\text{ }^\circ\text{C}$ — $9{,}4\text{ г/м}^3$).

| Дано: | Найти: |
| :--- | :--- |
| $t = 18\text{ }^\circ\text{C}$ | $\rho$ — ? |
| $t_p = 10\text{ }^\circ\text{C}$ | |
| $\rho_0(18\text{ }^\circ\text{C}) = 15{,}4\text{ г/м}^3$ | |
| $\rho_0(10\text{ }^\circ\text{C}) = 9{,}4\text{ г/м}^3$ | |

**Решение:**  
1. **Точка росы** ($t_p$) — это температура, до которой нужно изобарически охладить воздух данной влажности, чтобы содержащийся в нём пар стал насыщенным.  
2. При охлаждении до точки росы масса пара и объём существенно не меняются, следовательно, текущая абсолютная влажность воздуха в точности равна плотности насыщенного пара при температуре точки росы:  
   $$\rho = \rho_0(t_p)$$  
3. Из табличных данных: $\rho_0(10\text{ }^\circ\text{C}) = 9{,}4\text{ г/м}^3$.  
   Значит, $\rho = 9{,}4\text{ г/м}^3$.

**Ответ:** $\rho = 9{,}4\text{ г/м}^3$.

## Задача 11
###### Тип: Насыщенный пар (свойства и изотермические процессы)
**Условие:**
В закрытом сосуде находятся вода и её насыщенный пар. Как меняется плотность насыщенного водяного пара при повышении температуры сосуда, пока вся жидкость ещё не испарилась? Почему этот процесс происходит быстрее, чем в идеальном газе?

| Дано: | Найти: |
| :--- | :--- |
| Вода + пар | Характер изменения $\rho_0(T)$ |
| $T$ увеличивается | Объяснение отличия от идеального газа |

**Решение:**  
1. При нагревании средняя кинетическая энергия молекул жидкости возрастает. Всё большее число молекул преодолевает силы межмолекулярного притяжения и вылетает в газовую фазу.  
2. Дополнительное испарение приводит к росту массы пара в том же объёме, следовательно, концентрация и плотность насыщенного пара $\rho_0$ быстро **увеличиваются**.  
3. В идеальном газе постоянной массы плотность при постоянном объёме не зависит от температуры ($\rho = \text{const}$). У насыщенного же пара масса газа переменна: с ростом $T$ растёт не только кинетическая энергия частиц, но и их общее количество в объёме.

**Ответ:** плотность растёт быстрее, чем у идеального газа, за счёт дополнительного испарения жидкости.

## Задача 12
###### Тип: Изменение влажности и массы пара в замкнутом объеме
**Условие:**  
В цилиндре под поршнем при постоянной температуре находится воздух с относительной влажностью $60\%$. Какой станет относительная влажность воздуха, если объём под поршнем изотермически уменьшить в $2$ раза? Что произойдёт с паром?

| Дано: | Найти: |
| :--- | :--- |
| $\varphi_1 = 60\%$ | $\varphi_2$ — ? |
| $V_2 = V_1 / 2$ | Поведение пара |
| $T = \text{const}$ | |

**Решение:**  
1. При сжатии ненасыщенного пара его плотность увеличивается обратно пропорционально объёму:  
   $$\rho' = \rho_1 \cdot \frac{V_1}{V_2} = 2 \cdot \rho_1$$  
2. Соответственно, гипотетическая влажность должна была бы составить:  
   $$\varphi' = 2 \cdot \varphi_1 = 2 \cdot 60\% = 120\%$$  
3. Однако относительная влажность не может превышать $100\%$ в термодинамическом равновесии. Как только пар достигает насыщения ($\varphi = 100\%$), дальнейшее уменьшение объёма вызывает конденсацию пара в жидкость при постоянных $\rho_0$ и $p_0$.

**Ответ:** относительная влажность станет равной $100\%$; часть пара сконденсируется в воду.

## Задача 13
###### Тип: Качественные и прикладные вопросы влажности
**Условие:**  
Почему в жаркую погоду при температуре $+32\text{ }^\circ\text{C}$ человек чувствует себя значительно тяжелее при высокой относительной влажности воздуха ($85\%$), чем при низкой ($30\%$) при той же температуре?

| Дано: | Найти: |
| :--- | :--- |
| $t = +32\text{ }^\circ\text{C}$ | Причина ухудшения |
| $\varphi_{\text{выс}} = 85\%$ | самочувствия при высокой $\varphi$ |
| $\varphi_{\text{низ}} = 30\%$ | |

**Решение:**  
1. Основной механизм терморегуляции человека при высоких температурах окружающей среды — выделение и последующее испарение пота с поверхности кожи.  
2. Испарение — процесс, идущий с поглощением тепла (каждый грамм испарившейся воды уносит около $2400\text{ Дж}$ энергии), что охлаждает организм.  
3. При влажности $85\%$ воздух близок к насыщению, поэтому скорость испарения резко снижается. Пот выделяется, но стекает каплями, не испаряясь, из-за чего теплоотдача падает и наступает перегрев организма. При влажности $30\%$ пот испаряется быстро и эффективно охлаждает тело.

**Ответ:** высокая влажность препятствует испарению пота и нарушает естественное охлаждение тела.

<a id="Тип-7-смешение-воздушных-масс-комбинированные"></a>
## Задача 14
###### Тип: Смешение воздушных масс (Комбинированные)
**Условие:**  
В первом закрытом сосуде объёмом $1\text{ м}^3$ находится воздух с относительной влажностью $40\%$, а во втором сосуде объёмом $3\text{ м}^3$ при той же температуре — воздух с относительной влажностью $80\%$. Сосуды соединили тонкой трубкой. Какая относительная влажность установится после перемешивания при неизменной температуре?

| Дано: | Найти: |
| :--- | :--- |
| $V_1 = 1\text{ м}^3$ | $\varphi_{\text{общ}}$ — ? |
| $\varphi_1 = 40\%$ ($0{,}40$) | |
| $V_2 = 3\text{ м}^3$ | |
| $\varphi_2 = 80\%$ ($0{,}80$) | |
| $T = \text{const}$ | |

**Решение:**  
1. Пусть $\rho_0$ — плотность насыщенного водяного пара при данной постоянной температуре.  
2. Масса пара в первом сосуде:  
   $$m_1 = \rho_1 \cdot V_1 = (\varphi_1 \cdot \rho_0) \cdot V_1 = 0{,}40 \cdot \rho_0 \cdot 1 = 0{,}40\rho_0$$  
3. Масса пара во втором сосуде:  
   $$m_2 = \rho_2 \cdot V_2 = (\varphi_2 \cdot \rho_0) \cdot V_2 = 0{,}80 \cdot \rho_0 \cdot 3 = 2{,}40\rho_0$$  
4. Суммарная масса пара и общий объём системы:  
   $$m_{\text{общ}} = m_1 + m_2 = 0{,}40\rho_0 + 2{,}40\rho_0 = 2{,}80\rho_0$$  
   $$V_{\text{общ}} = V_1 + V_2 = 1 + 3 = 4\text{ м}^3$$  
5. Установившаяся плотность пара:  
   $$\rho_{\text{общ}} = \frac{m_{\text{общ}}}{V_{\text{общ}}} = \frac{2{,}80\rho_0}{4} = 0{,}70\rho_0$$  
6. Итоговая относительная влажность:  
   $$\varphi_{\text{общ}} = \frac{\rho_{\text{общ}}}{\rho_0} \cdot 100\% = 0{,}70 \cdot 100\% = 70\%$$

**Ответ:** $\varphi_{\text{общ}} = 70\%$.

<a id="Тип-3-психрометр-и-влажность"></a>
## Задача 15
###### Тип: Психрометр и влажность
**Условие:**  
Осенью в сырую туманную погоду показания сухого и влажного термометров психрометра на улице практически совпали. О чём это свидетельствует? Возможно ли в реальных условиях наблюдать показание влажного термометра выше сухого?

| Дано: | Найти: |
| :--- | :--- |
| $t_{\text{сух}} \approx t_{\text{вл}}$ | О чём свидетельствует равенство? |
| Туман на улице | Возможно ли $t_{\text{вл}} > t_{\text{сух}}$? |

**Решение:**  
1. Совпадение показаний означает отсутствие испарения с фитиля влажного термометра. Это прямо свидетельствует о том, что относительная влажность воздуха предельно высока и равна $100\%$ (туман как раз и представляет собой сконденсировавшийся насыщенный пар).  
2. В условиях динамического равновесия влажный термометр не может быть теплее сухого, так как испарение — процесс эндотермический (с поглощением энергии).  
3. Однако кратковременно ситуация $t_{\text{вл}} > t_{\text{сух}}$ возможна, если холодный психрометр занести с мороза в тёплое влажное помещение: на более холодном влажном термометре начнётся конденсация пара из тёплого воздуха с активным выделением скрытой теплоты парообразования.

**Ответ:** влажность равна $100\%$; показание влажного термометра выше сухого возможно кратковременно при конденсации пара на приборе.
