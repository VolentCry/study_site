## Задача 1
###### Тип: Нагрев
**Условие:**
![[Задача на тепло. Тип 1.png|736]]
Какое количество теплоты требуется для нагревания воды в аквариуме объемом 5 л от $10 °C$ до $60 °C$?  
(Плотность воды: ρ = $1000 \hspace{0.1cm} кг/м³$, удельная теплоемкость воды: c = $4200 \hspace{0.1cm} Дж/(кг · °C)$).

| Дано:                 | СИ:      | Найти: |
| :-------------------- | :------- | :----- |
| V = 5 л               | 0,005 м³ | Q — ?  |
| $t_1$ = 10 °C         |          |        |
| $t_2$ = 60 °C         |          |        |
| c = 4200 Дж/(кг · °C) |          |        |
| ρ = 1000 кг/м³        |          |        |

**Решение:**  
1. Найдем массу воды через плотность и объем:  
   m = ρ · V = 1000 · 0,005 = 5 кг  
2. Рассчитаем количество теплоты:  
   Q = c · m · ($t_2$ - $t_1$)
   Q = 4200 · 5 · (60 - 10) = 4200 · 5 · 50 = 1 050 000 Дж = 1,05 МДж  

**Ответ:** $Q = 1,05$ МДж.

## Задача 2
###### Тип: Нагрев + КПД + Сгорание
**Условие:**
![[Задача на тепло. Тип 2.png|759]]
Какую массу сухого спирта нужно сжечь в горелке с КПД $40\%$, чтобы нагреть 2 кг воды от $20 °C$ до кипения при $100 °C$?  
(Удельная теплота сгорания спирта: $q = 30 000 000 \hspace{0.1cm} Дж/кг$, удельная теплоемкость воды: $c = 4200 \hspace{0.1cm} Дж/(кг · °C)$).

| Дано:                 | СИ: | Найти:           |
| :-------------------- | :-- | :--------------- |
| $m_в$ = 2 кг          |     | $m_{спирта}$ — ? |
| $t_1$ = 20 °C         |     |                  |
| $t_2$ = 100 °C        |     |                  |
| КПД = 40%             | 0,4 |                  |
| q = 30 000 000 Дж/кг  |     |                  |
| c = 4200 Дж/(кг · °C) |     |                  |

**Решение:**  
1. Полезное тепло идет на нагревание воды:  
   Qполезное = c · $m_{воды}$ · ($t_2 - t_1$) = 4200 · 2 · 80 = 672 000 Дж  
2. С учетом КПД определим полное тепло, которое должно выделиться от сгорания топлива:  
   $Q_{зат} = Q_{полез}$ / КПД = 672 000 / 0,4 = 1 680 000 Дж  
3. Масса сжигаемого топлива:  
   $m_{спирта}$ = $Q_{зат}$ / q = 1 680 000 / 30 000 000 = 0,056 кг = 56 г  

**Ответ:** m_спирта = 56 г.

## Задача 3
###### Тип: Нагрев + Плавление
**Условие:**
![[Задача на тепло. Тип 3.png|839]]
Какое количество теплоты нужно затратить, чтобы кусок льда массой 0,5 кг при температуре -10 °C превратить в воду при температуре 0 °C?  
(Удельная теплоемкость льда: c = 2100 Дж/(кг · °C), удельная теплота плавления льда: λ = 330 000 Дж/кг).

| Дано:                 | Найти:          |
| :-------------------- | :-------------- |
| m = 0,5 кг            | $Q_{общее}$ — ? |
| $t_1$ = -10 °C        |                 |
| $t_{пл}$ = 0 °C       |                 |
| c = 2100 Дж/(кг · °C) |                 |
| λ = 330 000 Дж/кг     |                 |

**Решение:**  
1. Сначала лед нужно нагреть от -10 °C до температуры плавления 0 °C:  
   $Q_1 = c · m · (t_{пл} - t_1) = 2100 · 0,5 · (0 - (-10)) = 2100 · 0,5 · 10 = 10 500$ Дж  
2. Затем расплавить лед при постоянной температуре 0 °C:  
   $Q_2$ = λ · m = 330 000 · 0,5 = 165 000 Дж
3. Суммарная теплота:  
   $Q_{общее} = Q_1 + Q_2 = 10 500 + 165 000 = 175 500$ Дж = $175,5$ кДж  

**Ответ:** $Q_{общее}$ = 175,5 кДж.

## Задача 4
###### Тип: Уравнение теплового баланса
**Условие:**
![[Задача на тепло. Тип 4.png]]
Металлический цилиндр массой 0,2 кг, нагретый до 100 °C, опустили в воду массой 0,38 кг при 20 °C. Установилась общая температура 24 °C. Найдите удельную теплоемкость металла.  
(Удельная теплоемкость воды: c_воды = 4200 Дж/(кг · °C)).

| Дано:                     | Найти:    |
| :------------------------ | :-------- |
| $m_1$ = 0,2 кг            | $c_1$ — ? |
| $t_1$ = 100 °C            |           |
| $m_2$ = 0,38 кг           |           |
| $t_2$ = 20 °C             |           |
| $t_{общ}$ = 24 °C         |           |
| $c_2$ = 4200 Дж/(кг · °C) |           |

**Решение:**  
1. Тепло, отданное остывающим металлом:  
	$Q_{отд} = c_1 · m_1 · (t_1 - t_{общ}) = c_1 · 0,2 · (100 - 24) = c_1 · 0,2 · 76 = 15,2 · c_1$  
2. Тепло, полученное нагревающейся водой:  
	$Q_{получ} = c_2 · m_2 · (t_{общ} - t_2) = 4200 · 0,38 · (24 - 20) = 4200 · 0,38 · 4 = 6384$ Дж  
3. По закону теплового баланса Qотданное = Qполученное:  
   15,2 · $c_1$ = 6384  
   $c_1$ = 6384 / 15,2 = 420 Дж/(кг · °C)  

**Ответ:** $c_1$ = 420 Дж/(кг · °C).

## Задача 5
###### Тип: Уравнение теплового баланса + Нагрев + Плавление
**Условие:**
![[Задача на тепло. Тип 5.png|977]]
В воду массой 1 кг при 20 °C бросили кусок льда массой 0,2 кг при 0 °C. Растает ли весь лед и какая конечная температура установится?  
(Удельная теплоемкость воды: c = 4200 Дж/(кг · °C), удельная теплота плавления льда: λ = 330 000 Дж/кг).

| Дано:                   | Найти:                  |
| :---------------------- | :---------------------- |
| $m_{в}$ = 1 кг          | 1. Растает ли весь лед? |
| $t_{в}$ = 20 °C         | 2. $t_{общ}$ — ?        |
| $m_{л}$ = 0,2 кг        |                         |
| $t_{л}$ = 0 °C          |                         |
| λ = 330 000 Дж/кг       |                         |
| $c$ = 4200 Дж/(кг · °C) |                         |

**Решение:**  
1. Проверка возможности полного плавления:  
	Максимальное тепло, которое отдаст теплая вода при остывании до 0 °C: 
	$Q_{отд} = c · m_в · (t_в - 0) = 4200 · 1 · 20 = 84 000$ Дж  
	Теплота, необходимая для расплавления всей массы льда:  
	$Q_{плав} = λ · m_л = 330 000 · 0,2 = 66 000$ Дж  
	Сравнение: 84 000 Дж > 66 000 Дж. Значит, весь лед гарантированно растает, а остаток тепла пойдет на нагрев выше 0 °C.  
2. Уравнение теплового баланса:  
   Остывание воды = плавление льда + нагревание получившейся талой воды  
   $c · m_в · (t_в - t_{общ}) = λ · m_л + c · m_л · (t_{общ} - 0)$  
   $4200 · 1 · (20 - t_{общ}) = 66 000 + 4200 · 0,2 · t_{общ}$
   $84 000 - 4200 · t_{общ} = 66 000 + 840 · t_{общ}$  
   $84 000 - 66 000 = 5040 · t_{общ}$
   $18 000 = 5040 · t_{общ}$  
   $t_{общ} = 18 000 / 5040 ≈ 3,57 °C$  

**Ответ:** лед растает полностью; установившаяся температура ≈ 3,6 °C.

## Задача 6
###### Тип: Ток + КПД + Нагрев
**Условие:**
![[Задача на тепло. Тип 6.png]]
Чайник мощностью 2000 Вт с КПД 84% нагревает 1,5 кг воды от 20 °C до 100 °C. За сколько секунд закипит вода?  
(Удельная теплоемкость воды: c = 4200 Дж/(кг · °C)).

| Дано:                 | Найти:      |
| :-------------------- | :---------- |
| P = 2000 Вт           | время t — ? |
| $\eta$ = 0,84         |             |
| m = 1,5 кг            |             |
| $t_1$ = 20 °C         |             |
| $t_2$ = 100 °C        |             |
| c = 4200 Дж/(кг · °C) |             |

**Решение:**  
1. Полезное тепло на нагревание воды:  
   $Q_{полез} = c · m · (t_2 - t_1) = 4200 · 1,5 · 80 = 504 000$ Дж  
2. Полная электроэнергия с учетом КПД:  
   $A_{затрач} = Q_{полез} / \eta = 504 000 / 0,84 = 600 000$ Дж  
3. Время работы чайника (A = P · t):  
   $t = A_{затрач}/ P = 600 000 / 2000 = 300$ с  

**Ответ:** t = 300 с (5 минут).

## Задача 7
###### Тип: Энергия + Нагрев
**Условие:**
![[Задача на тепло. Тип 7.png]]
Свинцовая пуля летит со скоростью 200 м/с и застревает в земляном валу. На сколько градусов нагрелась пуля, если 70% ее кинетической энергии превратилось во внутреннюю энергию самой пули?  
(Удельная теплоемкость свинца: c = 140 Дж/(кг · °C)).

| Дано: | Найти: |
| :--- | :--- |
| v = 200 м/с | Δt — ? |
| k = 0,7 (70%) | |
| c = 140 Дж/(кг · °C) | |

**Решение:**  
1. Кинетическая энергия пули перед ударом:  
   $E_к$ = (m · v²) / 2  
2. Теплота, перешедшая в пулю:  
   Q = 0,7 · $E_к$ = 0,7 · (m · v²) / 2 = 0,35 · m · v²  
3. Теплота нагрева пули:  
   Q = c · m · Δt  
4. Приравниваем и сокращаем массу m:  
   c · m · Δt = 0,35 · m · v²  
   c · Δt = 0,35 · v²  
   Δt = (0,35 · v²) / c  
   Δt = (0,35 · 200²) / 140 = (0,35 · 40 000) / 140 = 14 000 / 140 = 100 °C  

**Ответ:** пуля нагрелась на 100 °C.

## Задача 8
###### Тип: Конденсация + Охлаждение
**Условие:**
![[Задача на тепло. Тип 8.png]]
Какое количество теплоты выделится в окружающую среду при конденсации 2 кг водяного пара, взятого при температуре 100 °C, и последующем охлаждении образовавшейся воды до 20 °C?  
(Удельная теплота парообразования воды: L = 2 300 000 Дж/кг, удельная теплоемкость воды: c = 4200 Дж/(кг · °C)).

| Дано:                 | Найти:          |
| :-------------------- | :-------------- |
| m = 2 кг              | $Q_{общее}$ — ? |
| $t_1$ = 100 °C        |                 |
| $t_2$ = 20 °C         |                 |
| L = 2 300 000 Дж/кг   |                 |
| c = 4200 Дж/(кг · °C) |                 |

**Решение:**  
Процесс состоит из двух последовательных этапов:

1. **Конденсация пара при постоянной температуре 100 °C:**  
   При фазовом переходе пара в жидкость выделяется теплота:  
   $Q_1 = L · m$  
   $Q_1 = 2 300 000 · 2 = 4 600 000$ Дж (4,6 МДж)

2. **Охлаждение образовавшейся горячей воды от 100 °C до 20 °C:**  
   $Q_2 = c · m · (t_1 - t_2)$
   $Q_2 = 4200 · 2 · (100 - 20) = 4200 · 2 · 80 = 672 000$ Дж (0,672 МДж)

3. **Общее количество выделившейся теплоты:**  
   $Q_{общее} = Q_1 + Q_2$  
   $Q_{общее} = 4 600 000 + 672 000 = 5 272 000 Дж$ ≈ 5,27 МДж  

**Ответ:** $Q_{общее}$ = 5,272 МДж (5 272 000 Дж).

## Задача 9
###### Тип: Уравнение теплового баланса + Нагрев + Парообразование
**Условие:**
![[Задача на тепло. Тип 9.png]]
В сосуд с холодной водой массой 5 кг при температуре 20 °C впустили 100 г водяного пара при температуре 100 °C. До какой температуры нагреется вода после полной конденсации пара и перемешивания? Потерями тепла в окружающую среду пренебречь.  
(L = 2 300 000 Дж/кг, c = 4200 Дж/(кг · °C)).

| Дано:                 | СИ:    | Найти:        |
| :-------------------- | :----- | :------------ |
| $m_в$ = 5 кг          |        | $t_{общ}$ — ? |
| $t_в$ = 20 °C         |        |               |
| $m_{пара}$ = 100 г    | 0,1 кг |               |
| $t_{пара}$ = 100 °C   |        |               |
| L = 2 300 000 Дж/кг   |        |               |
| c = 4200 Дж/(кг · °C) |        |               |

**Решение:**  
1. **Тепло, которое отдает пар при конденсации и остывании до температуры t_общ:**  
   * При конденсации:  
     $Q_1 = L · m_{пара} = 2 300 000 · 0,1 = 230 000$ Дж  
   * При остывании получившейся горячей воды:  
	 $Q_2 = c · m_{пара} · (t_{пара} - t_{общ}) = 4200 · 0,1 · (100 - t_{общ}) = 420 · (100 - t_{общ})$  
   * Суммарно отдано:  
     $Q_{отд} = 230 000 + 42 000 - 420 · t_{общ} = 272 000 - 420 · t_{общ}$  

1. **Тепло, которое получает холодная вода при нагревании:**
   $Q_{получ} = c · m_в · (t_{общ} - t_в)$
   $Q_{получ} = 4200 · 5 · (t_{общ} - 20) = 21 000 · (t_{общ} - 20) = 21 000 · t_{общ} - 420 000$

2. **Уравнение теплового баланса (Q_отданное = Q_полученное):**  
   $272 000 - 420 · t_{общ} = 21 000 · t_{общ} - 420 000$  
   $272 000 + 420 000 = 21 000 · t_{общ} + 420 · t_{общ}$
   $692 000 = 21 420 · t_{общ}$
   $t_{общ} = 692 000 / 21 420 ≈ 32,3 °C$

**Ответ:** установившаяся температура составит примерно 32,3 °C.

###### Тип: Тепло(Комбинированные)
**Условие:**
![[Задача на тепло. Задача 19.png]]
В тонкостенный стакан (теплоемкостью стакана можно пренебречь) с площадью поверхности **0,04 м²** налили **200 г** воды при температуре **0 °C** и положили **50 г** льда при **0 °C**. Стакан стоит в комнате при температуре **25 °C**. Коэффициент теплоотдачи от воздуха к стенкам стакана равен **12 Вт/(м²·К)**. Через какое время температура воды в стакане поднимется до **10 °C**? (При расчете этапа нагревания воды от **0 °C** до **10 °C** считать, что мощность теплопритока определяется средней разностью температур между комнатой и водой).
