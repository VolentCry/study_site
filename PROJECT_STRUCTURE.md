# Структура и назначение файлов проекта «НЕШкола»

Данный документ содержит полное описание назначения всех файлов основной директории проекта и целевых папок: `js/`, `css/`, `math_moduls/`, `pages/` и `tasks/`.

---

## 1. Файлы в корневой директории

| Имя файла | Описание и назначение |
|---|---|
| `main.py` | Главный бэкенд-сервер на **Flask**. Обрабатывает маршрутизацию, авторизацию (сессии, cookie, регистрация, вход), API для личного кабинета, домашние задания, методические планы, расписание, досье учеников и раздачу статических страниц. |
| `db.py` | Слой базы данных (**SQLite** `study_site.db`). Содержит схему БД, автомиграции (пользователи, классы, расписание, домашние задания, методические планы, сданные работы, метрики) и все функции выборки/записи данных. |
| `index.html` | Главная страница сайта. Презентует экосистему «НЕШкола», предметы, быстрый переход к классам, тренажёрам, авторизации и личному кабинету. |
| `profile.html` | Личный кабинет пользователя (ученика / учителя / родителя). Отображает XP, уровень, статистику решённых задач, динамику точности, прогресс в тренажёрах, список домашних заданий, расписание занятий и кастомизацию аватара/рамки. |
| `teacher.html` | Панель учителя / репетитора. Включает управление классами и учениками, конструктор домашних заданий, проверку сданных работ, расписание уроков, методические планы и подробные досье учеников со статистикой. |
| `homework.html` | Страница выполнения домашнего задания учеником. Динамически загружает составленное учителем Д/З, поддерживает черновики, проверку ответов и отправку на оценку. |
| `tasks_catalog.html` | Каталог интерактивных задач и тем с фильтрами по классам и предметам для самостоятельной практики. |
| `bank_tasks.html` | Банк типовых задач и тестовых заданий с пошаговым прорешиванием и проверкой. |
| `menu.html` | Мобильное или навигационное полноэкранное меню со ссылками на все разделы сайта, предметы и инструменты. |
| `404.html` | Страница ошибки 404 (страница не найдена) в фирменном стиле сайта. |
| `style.css` | Основной глобальный файл стилей сайта: переменные темы (шрифты, цвета, тени), сетка, типографика, кнопки и общие компоненты. |
| `config.env` | Файл конфигурации переменных окружения (секретные ключи сессий, режимы работы, пути). |
| `requirements.txt` | Список зависимостей Python для бэкенда (Flask, werkzeug и др.). |
| `package.json` / `package-lock.json` | Конфигурация зависимостей и скриптов экосистемы Node.js (при наличии утилит сборки/тестирования). |
| `study_site.db` | Основная база данных SQLite сайта. |
| `sitemap.xml` | Карта сайта XML для поисковых систем (SEO). |
| `robots.txt` | Инструкции для поисковых роботов по индексации разделов. |
| `README.md` | Описание репозитория, инструкции по запуску и обзор проекта. |
| `DESIGN.md` | Руководство по дизайн-системе (цветовая палитра, типографика, правила отступов, радиусы и компоненты). |
| `instruction.txt` | Дополнительные текстовые заметки и инструкции по работе с проектом. |
| `verify_login_display_name.js` | Тестовый скрипт для верификации отображаемого имени при входе пользователя. |
| `verify_methodical_plan.js` | Тестовый скрипт для проверки логики и структуры методических планов. |
| `profile_mobile_se.png` | Скриншот/мокап адаптивного отображения страницы профиля на мобильных устройствах. |
| `Идеи по улучшению сайта.pdf` | Документ с планами, идеями развития функционала и концепциями образовательной платформы. |
| `.gitignore` | Список файлов и директорий, исключаемых из системы контроля версий Git. |

## 2. Папка `js/` (Клиентская логика, тренажёры и данные)

| Имя файла | Описание и назначение |
|---|---|
| `auth_sync.js` | Синхронизация статуса авторизации, фоновое сохранение прогресса и обмен данными с сервером. |
| `main_index_logic.js` | Интерактивная логика главной страницы `index.html`: карусели, модальные окна, анимации и фильтры. |
| `all_profile_logic.js` | Главный скрипт личного кабинета `profile.html`: рендеринг профиля, XP, уровней, расписания, ДЗ и настроек. |
| `profile_metrics.js` | Расчёт графиков успеваемости, процента точности и статистики попыток в профиле. |
| `teacher_page_logic.js` | Главная клиентская логика панели учителя `teacher.html`: управление классами, назначение ДЗ, журнал, расписание, досье. |
| `homework_page_logic.js` | Клиентская логика страницы решения домашнего задания `homework.html`: автосохранение черновиков, отправка решения. |
| `methodical_plan.js` | Модуль конструктора методических планов занятий (редактор тем, привязка к урокам и ученикам). |
| `trainer_rank_tracker.js` | Единая система рангов, уровней и серий побед (streak) для всех тренажёров с сохранением в профиль. |
| `trainer_timed_mode.js` | Универсальный модуль игры на время («Сыграть на 10 минут!») для тренажёров ОГЭ. |
| `task_logic.js` | Движок прорешивания интерактивных заданий, подсказок и проверки ответов в каталогах задач. |
| `bank_tasks_data.js` | База данных вопросов и задач для банка заданий `bank_tasks.html`. |
| `bank_tasks_runner.js` | Логика работы и тестирования в банке заданий `bank_tasks.html`. |
| `oge_theory_data.js` | Справочник теоретических материалов, формул и спойлеров для дорожной карты ОГЭ (`oge_roadmap.html`). |
| `oge_task_6_trainer.js` | Генератор заданий ОГЭ №6: обыкновенные и десятичные дроби, степени и вычисления. |
| `oge_task_7_trainer.js` | Генератор заданий ОГЭ №7: числа на координатной прямой, сравнение и выбор верного утверждения. |
| `oge_task_8_trainer.js` | Генератор заданий ОГЭ №8: свойства степеней, корни, алгебраические выражения. |
| `oge_task_9_trainer.js` | Генератор заданий ОГЭ №9: линейные, квадратные, дробно-рациональные уравнения и системы. |
| `oge_task_10_trainer.js` | Генератор заданий ОГЭ №10: теория вероятностей (классическая вероятность, пирожки, билеты, монеты). |
| `oge_task_11_trainer.js` | Генератор заданий ОГЭ №11: графики функций (параболы, прямые, гиперболы, чтение формул и знаков коэффициентов). |
| `oge_task_13_trainer.js` | Генератор заданий ОГЭ №13: линейные и квадратные неравенства, системы неравенств, метод интервалов, штриховка на прямой. |
| `oge_task_18_trainer.js` | Генератор заданий ОГЭ №18: геометрия на клетках (площади фигур, тангенсы углов, средние линии, расстояния). |
| `oge_task_20_trainer.js` | Генератор заданий ОГЭ №20 (Часть 2, 2 балла): уравнения высших степеней, дробно-рациональные неравенства, системы. |
| `common_fraction_trainer.js` | Базовый тренажёр обыкновенных дробей: сложение, вычитание, умножение, деление. |
| `decimal_fraction_trainer.js` | Тренажёр действий с десятичными дробями. |
| `complex_fractions_trainer.js` | Тренажёр многоэтажных и составных дробей. |
| `complex_fractions_powers_trainer.js` | Тренажёр вычислений с многоэтажными дробями, содержащими степени. |
| `powers_trainer.js` | Тренажёр вычисления степеней и применения базовых свойств степеней. |
| `powers_compare_trainer.js` | Тренажёр сравнения степенных выражений и корней. |
| `divisibility_trainer.js` | Генератор заданий и модуль проверки для тренажёра «Проверка на делимость» (признаки делимости на 2, 3, 4, 5, 7, 9, 10) и конструктора домашних заданий. |
| `extract_whole_advanced_trainer.js` | Генератор заданий и модуль проверки для тренажёра «Выделение целой части в дробях (слож.)» (крупные 3- и 4-значные числа, перевод в десятичные дроби) и конструктора домашних заданий. |
| `multiplication_trainer.js` | Базовый тренажёр таблицы умножения (начальный уровень). |
| `multiplication_trainer_medium.js` | Тренажёр умножения среднего уровня сложности (двузначные числа, ограничение по времени). |
| `multiplication_trainer_hard.js` | Продвинутый тренажёр устного счёта и умножения сложных чисел. |
| `multiplication_test.js` | Тестовый режим проверки знания таблицы умножения. |
| `fsu_trainer.js` | Тренажёр формул сокращённого умножения (квадрат суммы/разности, разность квадратов). |
| `monomials_trainer.js` | Генератор заданий и модуль проверки для тренажёра «Одночлены» 7 класс (сложение, вычитание, умножение, деление, возведение в степень) и конструктора домашних заданий. |
| `math_tests.js` | Тестовые наборы и логика тестирования по курсу математики. |
| `physics_tests_8.js` | Банк тестовых заданий и вопросов по физике за 8 класс (тепловые явления, электричество, оптика). |
| `vocab_pre_a1.js` | Интерактивный тренажёр базовой лексики английского языка уровня Pre-A1 / начальная школа. |
| `genshin.js` | Логика тематической образовательной викторины/игры в стилистике Genshin Impact. |
| `genshin_quiz_data.js` | База вопросов и ответов для викторины Genshin Impact. |
